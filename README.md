# PFDA - Programming for Data Analytics

This repository contains coursework, assignments, labs, and project files for the Programming for Data Analytics course.

## Repository Structure

- **assignments/** - Course assignments organized by week
- **labs/** - Laboratory exercises and practice work
- **project/** - Final project files and data
- **docs/** - Documentation and helpful guides
